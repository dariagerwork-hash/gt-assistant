# AI-ассистент «Город Талантов» — Инструкция по запуску

## Что это

Чат-бот для жителей Кемерово, заполнивших анкету. Помогает с выбором жилья, анализом планировок, ипотекой и дизайном интерьера. Умеет анализировать фото планировок и генерировать ресайлинг интерьера в разных стилях.

---

## Страницы

| URL | Описание |
|---|---|
| `/` | Страница входа (имя + телефон) |
| `/chat` | Чат с ассистентом |
| `/admin` | Панель лидов (требует ADMIN_KEY) |

---

## Шаг 1 — Получить API-ключи

### Anthropic (Claude) — обязательно
1. Зайди на [console.anthropic.com](https://console.anthropic.com/settings/keys)
2. Создай новый API ключ
3. Скопируй его

### fal.ai (генерация интерьера) — для ресайлинга
1. Зайди на [fal.ai/dashboard/keys](https://fal.ai/dashboard/keys)
2. Создай ключ
3. Скопируй его

---

## Шаг 2 — Настроить переменные окружения

Файл `.env.local` уже создан в папке проекта. Открой его и вставь ключи:

```
ANTHROPIC_API_KEY=sk-ant-...ваш ключ...
FAL_KEY=...ваш ключ fal.ai...
ADMIN_KEY=gt_admin_2026
```

`ADMIN_KEY` — это пароль для входа в панель `/admin`. Можешь изменить на любой.

---

## Шаг 3 — Запустить локально

```bash
cd gt-assistant
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000)

---

## Шаг 4 — Задеплоить на Vercel

1. Зайди на [vercel.com](https://vercel.com) и создай аккаунт
2. Установи Vercel CLI: `npm i -g vercel`
3. В папке проекта запусти: `vercel`
4. Следуй инструкциям в терминале
5. После деплоя зайди в настройки проекта на Vercel → **Environment Variables**
6. Добавь три переменные: `ANTHROPIC_API_KEY`, `FAL_KEY`, `ADMIN_KEY`
7. Сделай редеплой: `vercel --prod`

---

## Как работает сбор лидов

- Каждый пользователь, заполнивший форму входа, сохраняется в `data/leads.json`
- Система автоматически ставит теги: «интересуется ГТ», «анализ планировок», «финансы», «интерьер»
- Панель лидов: `/admin` → введи `ADMIN_KEY`
- Данные обновляются каждые 30 секунд автоматически

**На Vercel**: `data/leads.json` не сохраняется между деплоями (serverless). Для продакшна подключи [Supabase](https://supabase.com) или [PlanetScale](https://planetscale.com) — это ~2 часа работы.

---

## Как обновить базу знаний ассистента

Файл `lib/system-prompt.ts` — это всё, что знает ассистент.  
Открой его и добавляй информацию в нужные разделы.

---

## Как добавить рендеры ГТ

В файле `app/chat/page.tsx` найди массив `GT_INFO` и добавь нужные разделы.  
Для отображения изображений добавь поле `image` к объекту раздела.
